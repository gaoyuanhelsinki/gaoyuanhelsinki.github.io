# 高源 | 芬兰赫尔辛基大学 | 北欧芬兰学派

## Gao Yuan | University of Helsinki | Finnish Lutheran School

高 源，男，1987年1月1日生，芬兰赫尔辛基大学哲学博士，博士后，研究员。师承“芬兰学派”重要奠基人Simo Knuuttila院士（欧洲科学院院士、芬兰科学院院士、瑞典皇家文学院Gad Rausing奖获得者、芬兰共和国雄狮勋章获得者）与Miikka Ruokanen教授（芬兰科学院多项国家重大项目首席专家、芬兰赫尔辛基大学教授），中国首位国家公派北欧芬兰获得欧洲思想史与文明互鉴领域博士学位者。长期聚焦欧洲区域国别视野下的中欧思想传统、文明互鉴与北极国家战略（“区域国别-思想根基-国家战略”三位一体）研究。

## 代表研究 | Selected Studies

### 1. 儒学在冰上丝路：芬兰儒学百年文化融构与当代理论镜鉴

系统研究：探察儒学在芬兰的译介、接受与文化融构，以及中欧文明互鉴中的理论和思想史。

[中文导读](https://gaoyuanhelsinki.cn/research/confucianism-finland/) · [English overview](https://gaoyuanhelsinki.cn/research/confucianism-finland/en/)

### 2. 道入北极：现存最早的冰岛文《老子》珍稀译本研究

系统分析：围绕早期冰岛文《老子》译本，考察中国哲学经典进入北欧的历史与诠释路径。

[中文导读](https://gaoyuanhelsinki.cn/research/laozi-iceland/) · [English overview](https://gaoyuanhelsinki.cn/research/laozi-iceland/en/)

### 3. 叩问东方之道：挪威探华进程中老学的最早译介与研究

系统分析：探察《老子》在挪威的早期译介与研究，以及跨文化思想交流中的文本理解。

[中文导读](https://gaoyuanhelsinki.cn/research/laozi-norway/) · [English overview](https://gaoyuanhelsinki.cn/research/laozi-norway/en/)

### 4. 柏拉图情感哲学的历史生成与理论转型

系统研究：考察柏拉图情感思想的发展，以及情感、理性与灵魂结构之间的关系。

[中文导读](https://gaoyuanhelsinki.cn/research/plato-emotions/) · [English overview](https://gaoyuanhelsinki.cn/research/plato-emotions/en/)
