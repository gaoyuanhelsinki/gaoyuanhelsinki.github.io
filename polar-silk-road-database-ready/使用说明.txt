使用说明

本包供现有 GitHub Pages 仓库使用，尚未部署。

1. 将 polar-silk-road-database 文件夹完整上传到仓库根目录，保留目录结构。
2. 打开 homepage-entry.html，复制全部内容。
3. 编辑现有根目录 index.html，搜索 <footer class="footer"，将入口代码粘贴在此 footer 开始标签之前。不要替换整个首页。若已经有 id="psr-home-entry"，应替换旧入口，避免重复。
4. 将 sitemap-additions.txt 中四个 <url> 节点加入现有 sitemap.xml 的 </urlset> 前。不要替换已有网址。
5. 提交到 main，等待 GitHub Pages 部署成功。
6. 检查 /polar-silk-road-database/ 及三个子目录页面。

内容说明：首批资源是现有研究页面的链接索引，不是原始扫描件或访谈全文。高宣扬、王宁人物专题标为待整理，不含虚构访谈。
检索在浏览器本地执行，范围为七条已公开链接的题名与标签，不含 PDF 正文；人物栏目未发布内容不列为已公开记录。
当前不需要 PHP 或数据库服务器，不需要修改首页导航，不依赖外部字体或脚本。将来可迁移至学校资源平台。
各页面带独立 canonical 与说明；未创建英文页面，不添加虚假的英文 hreflang。搜索引擎是否收录由其决定。
